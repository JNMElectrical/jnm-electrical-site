Garage Install

⚡ 7kW — full charge overnight

The go-to setup for most Hills District homes. A dedicated wall-mounted charger in your garage, ready every morning without thinking about it.

  • Dedicated 32A circuit from your switchboard
  • Wall-mounted charger unit — tidy, permanent
  • Works with all Type 2 EVs (Tesla adapter included)
  • Optional smart / app-controlled units
  • Two-car household? We can run dual circuits

Carport or Driveway

⚡ 7kW — outdoor rated

No garage? No problem. We install weatherproof chargers in carports, on exterior walls, and at driveway posts — done neatly and to code.

  • IP-rated outdoor charger units
  • Conduit run from switchboard — no exposed wiring
  • Wall, post, or pedestal mounting
  • Safe, tidy cable management
  • Suitable for all property types
